# Collaboration Instructions

- Implement only the change the user explicitly asks for. Do not broaden scope, alter
  behavior, or substitute a redesign without explicit approval.
- If you identify a risk, defect, or improvement outside that request, explain it in
  simple plain language, state the practical impact, suggest an option, and wait for the
  user's direction.
- If the user does not authorize that additional change, leave it unchanged.
