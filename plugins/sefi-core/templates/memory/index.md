# Memory Journalist Router

This local, private router points to structured session notes. Runtime `memory/` is
ignored by Git and never included in packages. Read a relevant note only when the current
task needs it. Do not hand-edit the generated block.

## Sessions

- `sessions/YYYY/MM/` -- one privacy-filtered Markdown note for each substantial work
  session.

Use `/sefi:close-session` to finish a session explicitly. `/sefi:memory-index rebuild`
rebuilds the disposable local search index from these Markdown notes.
