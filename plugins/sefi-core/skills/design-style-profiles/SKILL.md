# Design Style Profiles

Profiles tune a direction selected by UI/UX Designer; they never become a competing
direction system. All factual output follows the anti-hallucination skill: cite or mark
UNKNOWN, never guess.

## Rule block
Craft skill. Record exactly one profile with three 1-10 values: Ornament, Information
density, and Contrast. The default is 5 / 3 / 5 unless the brief or existing product gives
stronger evidence. A profile cannot choose a new direction or cannot replace the selected
direction, Product Context, motion specification, or component-library decision.

| Profile | Tuning intent |
| --- | --- |
| Soft Premium | Controlled depth, tactile rounding, warm restraint, and measured ornament. |
| Minimal Editorial | Typographic rhythm, quiet surfaces, deliberate whitespace, and low ornament. |
| Industrial Brutalist | Exposed structure, hard edges, high contrast, and functional density. |
| Custom | A documented, evidence-based adjustment that stays inside the selected direction. |

## Use
Tune tokens, borders, depth, typography treatment, and composition only after Product
Context and direction are explicit. State why each non-default value serves the primary
task. Preserve accessibility, resilient content, reduced-motion, and library boundaries.
